git init – создать новый репозиторий в текущей папке
git clone <url> – скопировать удалённый репозиторий к себе на компьютер
git status – посмотреть, какие файлы изменены и что готово к коммиту
git add <файл> – добавить изменения указанного файла в следующую фиксацию (индексация)
git commit – зафиксировать проиндексированные изменения с комментарием
git push – отправить свои коммиты в удалённый репозиторий
git pull – скачать и применить изменения из удалённого репозитория в свою ветку
git fetch – скачать изменения из удалённого репозитория, но не сливать их с текущей веткой
git branch – показать список веток или создать новую (git branch <имя>)
git checkout <ветка> – переключиться на другую ветку (или восстановить файл)
git merge <ветка> – слить изменения из указанной ветки в текущую
git log – показать историю коммитов
